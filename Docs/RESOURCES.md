## 🚀 Getting Started (Step-by-Step)

### Day 1: Gather Assets
1. Create `Assets/Downloaded` folder
2. Download 3 zombie models from Sketchfab
3. Download weapon models (pistol, rifle)
4. Download 10 Mixamo animations
5. Download Kenney city kit
6. Organize in folders (Models, Textures, Audio)

### Day 2: Install Tools
1. Install Blender (for editing models)
2. Install Audacity (for audio)
3. Install GIMP or Krita (for textures)
4. Bookmark learning resources

### Day 3: Unity Setup
1. Create new Unity project (URP template)
2. Install packages (Netcode, Input System)
3. Import downloaded assets
4. Test import (spawn zombie, check animations)

**Then:** Start Week 1 development (ROADMAP.md)

## 📝 License Reminder

**Always Check Licenses:**
- **CC0:** Public domain, use freely
- **CC-BY:** Use freely, give credit
- **CC-BY-NC:** Free for non-commercial only
- **Royalty-Free:** Check specific terms

**How to Credit:**
Create `CREDITS.txt` in game with:
```
3D Models:
- Zombie Model by [Artist] (Sketchfab) - CC-BY 4.0

Audio:
- Gunshot SFX by [Artist] (Freesound) - CC-BY 3.0

Music:
- Dark Fog by Kevin MacLeod (Incompetech) - CC-BY 3.0
```
