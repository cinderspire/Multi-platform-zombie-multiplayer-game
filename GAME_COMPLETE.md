## 🎮 HOW TO USE

### **Scene Setup**
1. Create NetworkManager GameObject
2. Add all system managers as children
3. Set up spawn points for players
4. Configure NavMesh for AI
5. Set up UI Canvas

### **Player Setup**
1. Add PlayerController component
2. Add CameraController as child
3. Add CharacterController
4. Configure layers and tags

### **AI Setup**
1. Place spawn points
2. Add zombie prefabs to SpawnerSystem
3. Bake NavMesh
4. Configure wave settings

### **Network Setup**
1. Configure NetworkManager
2. Set player prefab
3. Set network transport
4. Configure spawn manager
